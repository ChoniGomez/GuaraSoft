> **GuaraSoft** es una solución de software orientada al sector automotriz, diseñada específicamente para gestionar y optimizar los procesos de servicio de postventa. Permite llevar un control riguroso sobre el historial de los vehículos, los mantenimientos realizados y la atención al cliente, garantizando la persistencia de datos de forma segura y estructurada.

---

## 🌟 Características Principales

- 🚙 **Gestión de Vehículos y Clientes:** Registro detallado de clientes, vehículos asociados (modelo, patente, VIN) y su información relevante.
- 🔧 **Historial de Mantenimiento:** Seguimiento de los servicios de postventa, reparaciones, revisiones técnicas y garantías aplicadas a cada automóvil.
- 🗄️ **Mapeo Objeto-Relacional (ORM):** Implementación de **JPA (Java Persistence API)** para mapear eficientemente las clases y objetos de Java directamente a las tablas de la base de datos relacional.
- 🔒 **Persistencia Segura y Escalable:** Almacenamiento centralizado y robusto utilizando el motor de base de datos **PostgreSQL**.

---

## 🛠️ Tecnologías y Arquitectura

Este proyecto fue desarrollado bajo el paradigma de la Programación Orientada a Objetos (POO) y buenas prácticas de persistencia:

- **Lenguaje Principal:** Java.
- **ORM / Persistencia:** JPA (Java Persistence API).
- **Base de Datos:** PostgreSQL.
- **Entorno de Desarrollo (IDE):** NetBeans.
